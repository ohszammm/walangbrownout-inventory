# WalangBrownout Inventory (Frontend)

React + React Router prototype for the WalangBrownout Appliances inventory
system - CCS112 Application Development and Emerging Technologies,
University of Cabuyao, 3CS-B.

See `TEAM_CONTRIBUTION_GUIDE.md` for the full task breakdown and git workflow.

## Run it

npm install
npm run dev

Then open the printed local URL (typically http://localhost:5173).

## Status

This is the initial scaffold. Routing, state management (src/state,
src/utils, src/data), and the build config are wired and working. Every
other file is a `TODO` placeholder - see the file itself and
TEAM_CONTRIBUTION_GUIDE.md for who owns it and what it should become.
